Part A — Short Answer Questions

Q1
What is Machine Vision? 🤖
2 Marks
Machine Vision is the ability of a computer or machine to interpret and understand visual information from the real world using cameras, sensors, and image processing algorithms.

It enables machines to inspect, identify, measure, and guide objects automatically without human intervention. It combines hardware (cameras, lighting, sensors) and software (image processing, AI) to replicate human visual capabilities in industrial and robotic systems.

📌 Used in: industrial automation, quality control, robotics, autonomous vehicles.

Q2
Define feature of an image. 🔍
2 Marks
A feature of an image is a meaningful or distinctive piece of information extracted from the image that helps in understanding its content.

Features can be edges, corners, blobs, textures, or keypoints. They are used in tasks like object detection, recognition, and matching.

✅ A good feature is: unique, repeatable, and invariant to scale, rotation, and illumination changes.

Q3
What is contrast enhancement? 🎨
2 Marks
Contrast enhancement is an image processing technique used to improve the visual quality of an image by increasing the difference between bright and dark regions.

It makes the image clearer and easier to analyze. Common methods include:

🔹Histogram Equalization — redistributes pixel intensities uniformly
🔹Gray Value Transformation — maps input to output intensities
🔹Contrast Stretching — linearly expands the intensity range
Q4
Write any two examples of features in any image. 📐
2 Marks
1️⃣Edges — Boundaries between regions of different intensities, such as the outline of an object. Detected using Sobel, Canny operators.
2️⃣Corners — Points where two edges meet at an angle (e.g., corner of a box). Highly distinctive; used in Harris Corner Detector and feature matching.
Q5
What is template matching? 🧩
2 Marks
Template matching is a technique where a small image (template) is slid over a larger image to find regions that closely resemble the template.

It computes a similarity score at each position and identifies the best match. Common measures:

SSD: Σ(I(x,y) - T(x,y))² | NCC: Normalized Cross-Correlation

📌 Used in: object detection, pattern recognition, face detection.

Q6
Why YCrCb preferred over RGB for natural images? 🌈
2 Marks

YCrCb separates luminance (Y) from chrominance (Cr, Cb) components:

✅In natural images, lighting changes affect brightness more than color. By separating them, algorithms process color independently of brightness — making them robust to lighting variations.
❌RGB mixes color and brightness together, making it sensitive to illumination changes.

📌 Hence YCrCb is preferred for skin detection, face detection, and segmentation tasks.

Q7
Write any two algorithms for image classification. 🧠
2 Marks
1️⃣CNN (Convolutional Neural Networks) — Deep learning models that automatically learn spatial features from images using convolutional layers. Example: VGG, ResNet.
2️⃣SVM (Support Vector Machine) — Classifies images by finding the optimal hyperplane that separates different classes in feature space.
Q8
Write any two tracking algorithms. 🎯
2 Marks
1️⃣Kalman Filter — A recursive algorithm that estimates the position of a moving object by predicting its future state based on previous states and correcting it using new measurements.
2️⃣Mean Shift Algorithm — Tracks objects based on color histograms by iteratively finding the mode (peak) of a probability density function.

Q14
What is stereo reconstruction? 📷📷
2 Marks
Stereo reconstruction is the process of recovering 3D depth information from two 2D images taken from two slightly different viewpoints (like human eyes).
Z = (f × B) / d where Z=depth, f=focal length, B=baseline, d=disparity

📌 Used in robotics for 3D mapping, obstacle detection, and navigation.

Q15
What is similarity transformation? 📐
2 Marks
A similarity transformation preserves the shape of an object but may change its size and position. It includes translation, rotation, and uniform scaling.

✅ Angles between lines are preserved. ✅ Ratio of distances remains constant.

📌 Has 4 degrees of freedom in 2D: 2 (translation) + 1 (rotation) + 1 (scale).

Q16
What is transfer learning? 🔄
2 Marks
Transfer learning is a technique where a model trained on one large dataset (e.g., ImageNet) is reused and fine-tuned for a different but related task.

Instead of training from scratch, the pre-trained model's learned features are transferred to the new task. This saves time, reduces data requirements, and improves accuracy.

📌 Example: Using pre-trained VGG or ResNet for a custom image classification task.

Q17
What is iconic image processing? 🖼️
2 Marks
Iconic image processing refers to operations performed directly on image pixels without understanding the content of the image. Both input and output are images.

It includes operations like filtering, enhancement, smoothing, and edge detection. The image retains its original structure but is transformed in quality or appearance.

📌 X-axis: Pixel intensity levels (0–255)  |  Y-axis: Number of pixels at each intensity

Used for: contrast analysis, thresholding, and histogram equalization.

Q20
What is the focal length of a camera? 📷
2 Marks
Focal length is the distance between the camera's optical center (lens) and the image sensor when focused at infinity. Measured in millimeters (mm).
🔹Short focal length → Wider field of view (wide-angle)
🔹Long focal length → Narrower, magnified view (telephoto)
Q21
Define dispersion. 🌈
2 Marks
Dispersion is the phenomenon where different wavelengths (colors) of light are refracted by different amounts when passing through a medium like a lens or prism.

This causes chromatic aberration in camera lenses, where different colors focus at slightly different points, reducing image sharpness.

📌 In machine vision, dispersion is minimized using achromatic lenses.

Q22
What is rigid transformation? 📏
2 Marks
A rigid transformation (Euclidean transformation) preserves both the shape and size of an object. It includes only translation and rotation — no scaling or shearing.

✅ Distances between all points remain unchanged after transformation.

📌 Has 3 degrees of freedom in 2D: 2 (translation) + 1 (rotation).

Q23
Write any two challenges in object recognition using a single view. 👁️
2 Marks
1️⃣Occlusion — Parts of the object may be hidden behind other objects, making recognition incomplete and unreliable.
2️⃣Viewpoint variation — The same object looks very different from different angles, making it hard to match against a stored model.
Q24
What is multi-image processing? 📸📸
2 Marks
Multi-image processing uses multiple images of the same scene or object to extract more accurate or complete information than a single image provides.

Examples: Stereo vision (depth), image stitching (panorama), HDR imaging (dynamic range), temporal filtering (noise reduction from multiple frames).

Q25
What are SIFT features? 🔑
2 Marks
SIFT (Scale-Invariant Feature Transform) features are distinctive local image features invariant to scale, rotation, and partially invariant to illumination and viewpoint changes.

Detects keypoints using Difference of Gaussians (DoG) at multiple scales and computes a 128-dimensional descriptor based on gradient orientations.

📌 Used in: image matching, object recognition, panorama stitching.

Q26
What is bin number in spatiograms? 📦
2 Marks
In spatiograms, the bin number is the index of a specific histogram bin that stores both the frequency of pixel values AND the spatial statistics (mean position and covariance) within that bin.

Unlike regular histograms (only frequency), spatiograms store spatial information per bin, enabling location-aware feature matching for object tracking and recognition.

B1
Write about the components of a typical machine vision system. 🏭
10 Marks
Lighting → Lens → Camera → Frame Grabber → Computer → Software → Output / Actuator
⚙️ 1. Illumination / Lighting System

The most critical component. It illuminates the object to highlight important features. Types: backlighting (silhouette), diffuse lighting (uniform, no shadows), structured lighting (3D analysis), strobed lighting (fast-moving objects). LEDs are preferred.

🔭 2. Lens / Optics

Focuses light from the scene onto the image sensor. Key parameters: focal length (field of view), aperture (depth of field). Telecentric lenses eliminate perspective distortion and are preferred in metrology.

📷 3. Camera / Image Sensor

Converts light into digital signals. CCD: high quality, low noise, expensive. CMOS: faster, cheaper, lower power. Cameras can be area scan (full frame) or line scan (for moving objects on conveyor belts).

💾 4. Frame Grabber

Hardware that digitizes analog camera signals and transfers them to computer memory at high speed. Modern systems use digital interfaces: USB3, GigE, Camera Link.

🖥️ 5. Computer / Processor

Receives digitized images, runs vision algorithms, makes decisions. Modern systems use GPUs for accelerated deep learning inference.

💻 6. Image Processing Software

Libraries like OpenCV perform: preprocessing, segmentation, feature extraction, object detection, measurement. Proprietary options: HALCON, Cognex VisionPro.

🤖 7. Output / Actuation System

Based on results, sends control signals to actuators, robotic arms, conveyor belts, or alarm systems. Output can be pass/fail signals, coordinates, or measurement data.

🔌 8. Communication Interface

Connects vision system to machines via industrial protocols: Ethernet, RS-232, Profibus, or I/O signals.

Explain in detail about different types of light sources used in machine vision. 💡
10 Marks
💡Proper lighting is the foundation of any machine vision system. Poor lighting leads to poor image quality and unreliable results regardless of software quality.
🔵 1. LED (Light Emitting Diode) Lights

Most widely used. Available in white, red, blue, infrared wavelengths. Advantages: 50,000+ hour lifespan, energy-efficient, fast switching for strobed use, consistent brightness, compact. Used as ring lights, bar lights, dome lights, backlights.

⚪ 2. Fluorescent Lights

Produce diffuse, even illumination. Disadvantage: slow switching (cannot be strobed), brightness degrades over time, warm-up time needed. Mostly replaced by LEDs.

🟡 3. Halogen / Incandescent Lights

Bright white light but generate significant heat. Short lifespan, high energy consumption. Rarely used due to heat-induced damage to objects and sensors.

🔴 4. Fiber Optic Lights

Use optical fibers to deliver light from a remote source. Ideal when the object is heat-sensitive or in hard-to-reach locations. Light source placed away from inspection zone.

🔆 5. Laser Lights

Highly coherent, monochromatic, directional. Used in laser triangulation for 3D measurement and structured light systems. Line lasers project a stripe for 3D profiling.

🌑 6. Infrared (IR) Lights

Invisible to human eye but detectable by IR-sensitive cameras. Used for objects sensitive to visible light or covert machine vision systems.

🟣 7. Ultraviolet (UV) Lights

Cause certain materials to fluoresce, revealing features invisible under normal light. Used in inspection of PCBs, pharmaceutical tablets, and counterfeit detection.

Explain how an object can be segmented using thresholding method. ✂️
10 Marks
Image segmentation partitions an image into meaningful regions. Thresholding is the simplest and most widely used segmentation technique.
📐 Core Concept
If f(x,y) ≥ T → pixel = 1 (foreground/object) If f(x,y) < T → pixel = 0 (background)

This produces a binary image where the object is separated from the background.

🔹 Types of Thresholding
1️⃣Global Thresholding — Single threshold T applied to entire image. Simple and fast. Works when object and background have clearly distinct intensity levels. Fails with uneven illumination.
2️⃣Adaptive (Local) Thresholding — Different threshold computed for each small region based on local statistics. Handles non-uniform illumination effectively. Example: Adaptive Gaussian Thresholding in OpenCV.
3️⃣Otsu's Thresholding — Automatic method that selects optimal T by maximizing inter-class variance. No manual threshold selection needed. Works best for bimodal histograms.
Otsu's: Maximize σ²_B = w₀w₁(μ₀ - μ₁)² where w₀,w₁ = class probabilities, μ₀,μ₁ = class means
4️⃣Multi-level Thresholding — Multiple threshold values T₁, T₂... segment the image into more than two classes.
📋 Steps for Thresholding Segmentation
1
Convert input color image to grayscale
2
Plot the histogram of pixel intensities
3
Select threshold T (manually or via Otsu's method)
4
Apply threshold: create binary image
5
Apply morphological operations (dilation, erosion) to clean noise
6
Identify connected components (blobs) as segmented objects
AdvantagesLimitations
✅ Simple and computationally fast❌ Sensitive to noise
✅ Easy to implement❌ Fails with non-uniform illumination
✅ Works well for bimodal histograms❌ No spatial relationship between pixels
B4
Summarize the method of gray value transformation and contrast enhancement. 🎨
10 Marks
A gray value transformation maps input pixel intensities to new output intensities: s = T(r), where r = input pixel value, s = output pixel value.
🔸 Types of Gray Value Transformations
1️⃣Identity: s = r → No change. Used as reference.
2️⃣Negative (Inversion): s = 255 - r → Photographic negative. Used in medical imaging.
3️⃣Log Transformation: s = c × log(1 + r) → Compresses high intensities, expands dark regions. Used for Fourier spectrum display.
4️⃣Power-Law (Gamma): s = c × r^γ → γ < 1 brightens; γ > 1 darkens. Used for display gamma correction.
5️⃣Piecewise-Linear (Contrast Stretching): Different linear functions for different intensity ranges. Enhances specific intensity bands.
🎯 Contrast Enhancement Methods
📊Histogram Equalization — Redistributes pixel intensities uniformly using CDF. Formula: s_k = (L-1) × CDF(r_k). Enhances global contrast. Limitation: may over-enhance or produce unnatural results.
📈Contrast Stretching — s = (r - r_min)/(r_max - r_min) × 255. Simpler linear method.
🧩CLAHE — Applies histogram equalization locally in small tiles. Limits contrast enhancement to avoid amplifying noise. Widely used in medical imaging.

B6
Why is camera calibration important? Explain how camera calibration is done. 📐
10 Marks
🎯 Importance of Camera Calibration

A camera introduces distortions due to imperfect lenses and sensor placement. Calibration determines intrinsic and extrinsic parameters to correct these distortions and relate 3D world coordinates to 2D image coordinates.

⚠️Without calibration: measurements are inaccurate, 3D reconstruction fails, stereo vision has errors, AR overlays misalign.
📋 Camera Parameters
🔹Intrinsic: Focal length (fx, fy), Principal point (cx, cy), Distortion coefficients (k1, k2, k3, p1, p2)
🔹Extrinsic: Rotation matrix R + Translation vector T (camera position in world)
Camera Matrix K = [fx 0 cx] [0 fy cy] [0 0 1]
📋 Steps — Zhang's Method (Most Widely Used)
1
Prepare Calibration Pattern — Checkerboard with known square sizes; 3D coordinates of corners are known (z=0)
2
Capture Multiple Images — 10–20 images from different angles, distances, orientations
3
Detect Corners — Sub-pixel corner detection using cv2.findChessboardCorners()
4
Compute Homographies — For each image, compute H mapping 3D board coordinates to 2D image coordinates
5
Solve for Intrinsic Parameters — Camera matrix K computed by solving system of linear equations
6
Solve for Distortion Coefficients — Minimize reprojection error to estimate lens distortion
7
Solve for Extrinsic Parameters — R and T computed for each image from K and H
8
Optimization — Bundle Adjustment using Levenberg-Marquardt to minimize total reprojection error
✅Reprojection error < 1 pixel indicates a good calibration.

B8
Explain stereo reconstruction. 📷📷
10 Marks
Stereo reconstruction recovers the 3D structure of a scene from two 2D images taken from two different viewpoints, simulating binocular human vision.
📐 Core Principle

Same 3D point appears at different positions in left and right images — this difference is called disparity. Depth is inversely proportional to disparity.

Z = (f × B) / d where Z = depth, f = focal length, B = baseline (distance between cameras), d = disparity
📋 Steps in Stereo Reconstruction
1
Camera Calibration — Calibrate both cameras individually; stereo calibration finds relative rotation R and translation T between cameras
2
Stereo Rectification — Warp both images so corresponding points lie on the same horizontal scanline (simplifies search to 1D)
3
Correspondence Matching — Find matching pixels between left and right images using Block Matching (BM), SGBM, or deep learning methods
4
Disparity Map — Create map where each pixel stores disparity d. Brighter = closer objects
5
3D Point Cloud — Use Z = (f×B)/d to compute depth for each pixel; combined with (u,v) gives full 3D coordinates (X,Y,Z)
6
Visualization — 3D point cloud visualized using PCL or Open3D for mapping, object detection, navigation
ChallengeCause
Homogeneous regionsNo texture → ambiguous matching
OcclusionRegions visible in one camera but hidden in other
Lighting differencesDifferent exposure between two cameras
B9
Explain the recognition by linear combination of models using two views only. 🧮
10 Marks
This method (Ullman & Basri) shows that any 2D image of a 3D object under orthographic projection can be expressed as a linear combination of a small set of stored 2D model views.
📐 Mathematical Formulation
V_new = α₁V₁ + α₂V₂ + ... + αₙVₙ where V₁...Vₙ = stored 2D views, α₁...αₙ = scalar coefficients With two views: V_new = α₁V₁ + α₂V₂ + α₃V₃
📋 Steps for Recognition
🔷Training: Capture 2–3 stored 2D views. Identify correspondence points. Precompute linear combination coefficients for a range of viewpoints.
🔷Testing: Express the new input image as a linear combination of stored views. Find optimal coefficients α by solving a least-squares problem. Small residual error → object recognized. Large error → not recognized.
AdvantagesLimitations
✅ Computationally efficient❌ Assumes orthographic projection
✅ Only 2–3 views needed❌ Requires accurate point correspondences
✅ No full 3D model needed❌ Sensitive to occlusion and noise
💡Significance: Groundbreaking approach showing 3D object recognition can be reduced to 2D image algebra, eliminating the need for full 3D model storage.

Explain the steps of object recognition using only a single view. 👁️
10 Marks

B12
Describe about mapping SONAR data. 🔊
10 Marks
Sonar (Sound Navigation and Ranging) uses ultrasonic sound waves to measure distances. Widely used in mobile robots for obstacle avoidance and environment mapping.
📐 Principle
d = (v × t) / 2 where d = distance, v = speed of sound (≈343 m/s in air), t = round-trip time
📍 Sonar Data to Cartesian Coordinates
X = d × cos(θ) Y = d × sin(θ) where θ = sensor angle direction
⚠️ Challenges in Sonar Mapping
❌Wide beam angle (15°–30°) — Uncertain exactly where in cone reflection originated → angular uncertainty
❌Specular reflection — Smooth surfaces reflect sound away from sensor (like a mirror) → missed detections
❌Crosstalk — Multiple sonars interfering by picking up each other's echoes
🗺️ Occupancy Grid Mapping

Environment divided into grid cells. Each cell stores a probability (0 to 1) of being occupied:

🟢Cells along beam path closer than d → free (low probability)
🔴Cell at distance d → occupied (high probability)
⚪Cells beyond d → unknown
Bayesian update: P(occ|z) = [P(z|occ) × P(occ)] / P(z)

📌 Applications: indoor robot navigation, underwater ROV mapping, automobile parking assist.

B13
Explain how LASER scan measurements are aligned. 🔴
10 Marks
As a robot moves, LASER (LIDAR) scans taken at different positions must be aligned (registered) with each other to build a consistent map. This is called scan matching.
🎯 Problem Statement

Given two scans S₁ (reference) and S₂ (new), find transformation T (rotation R + translation t) that best aligns S₂ to S₁.

🔵 ICP (Iterative Closest Point) — Most Widely Used
1
For each point in S₂, find nearest point in S₁ (closest point correspondence)
2
Compute transformation T(R,t) minimizing: Σ ||pᵢ - T×qᵢ||²
3
Apply transformation T to S₂
4
Repeat until error converges below threshold
🟢 NDT (Normal Distributions Transform)

Divides reference scan into cells; models each as a Gaussian distribution. Aligns new scan by maximizing likelihood under Gaussian models. More robust than ICP for sparse point clouds.

🔄 Role in SLAM

Successive scan alignment gives robot's relative motion (odometry correction). Accumulated alignments build a global map. Loop closure detects revisited areas and corrects accumulated drift.

Error SourceCause
Sensor noiseInaccurate distance measurements
Dynamic obstaclesMoving people/vehicles change the scan
Featureless environmentsLong corridors — ambiguous matching
Fast robot motionMotion blur in scan

🔴 Issue 1: The Semantic Gap
The semantic gap is the difference between the low-level pixel data a computer sees and the high-level meaning a human instantly perceives.
👁️Human sees: "A dog sitting on a green sofa near a window."
🖥️Computer sees: [[122, 134, 119], [200, 198, 205], ...] — just numbers

There is no direct mathematical mapping from pixel values to semantic concepts. The same concept appears in infinite visual forms (different dog breeds, poses, lighting). Deep learning has partially bridged this gap but not fully closed it.

🔵 Issue 2: Variations in Visual Appearance
The same object can appear extremely different while different objects can appear very similar.
☀️Illumination variation — Object under sunlight vs dim indoor light looks completely different
🔄Viewpoint variation — A chair from front, side, top, 45° looks drastically different
📏Scale variation — Same car appears small rectangle far away vs large nearby
🙈Occlusion — Object partially hidden; person behind table shows only upper body
🐱Deformation — Non-rigid objects change shape (cat in different poses)
🔀Intra-class variation — All chairs are chairs but look vastly different
😕Inter-class similarity — Chihuahua vs muffin — different objects look very similar!
💡Deep neural networks handle many variations through data augmentation and large datasets, but still fail on adversarial examples.

Why classification algorithms are used in landmark spatiograms? 🗺️
10 Marks
📊 What are Spatiograms?
A spatiogram extends a color histogram by additionally storing spatial statistics (mean position μₓ,μᵧ and covariance Σ) for pixels within each histogram bin. Unlike histograms (frequency only), spatiograms are location-aware.
🗺️ Landmark Spatiograms

Landmark spatiograms represent specific distinctive points/regions of an object. Each landmark has a spatiogram capturing both color distribution and spatial extent.

❓ Why Classification Algorithms?
1️⃣Distinguishing Similar Landmarks — Different landmarks (eye, nose, mouth) may have similar color histograms. Classification uses full spatiogram (color + spatial) to distinguish accurately.
2️⃣Handling Appearance Changes — Viewpoint/lighting changes the spatiogram. Classifiers trained on multiple examples generalize and correctly classify despite these changes.
3️⃣Robust Matching — Simple histogram matching is insufficient for ambiguous regions. Classifiers evaluate multiple features simultaneously for reliable decisions.
4️⃣Efficiency in Large Databases — Trained classifiers quickly predict landmark class without exhaustive comparison to all stored spatiograms.
5️⃣Handling Partial Occlusion — When landmark is occluded, probabilistic classifiers still identify it from partial information.
AlgorithmHow it's Used
SVMOptimal boundary between landmark classes
kNNClassify based on k nearest spatiogram neighbors
Naive BayesProbabilistic model for each class
Random ForestEnsemble of decision trees for robust classification

Enumerate the steps of the condensation algorithm. 🎲
10 Marks
The CONDENSATION (CONditional DENSity propAGATION) algorithm, also known as Particle Filter, is a sequential Monte Carlo method for tracking objects in video using weighted samples (particles).
StepOperation
1️⃣ InitializationN particles with equal weights wᵢ = 1/N
2️⃣ PredictionPropagate using motion model + noise
3️⃣ WeightingWeight by observation likelihood
4️⃣ NormalizationNormalize weights to sum to 1
5️⃣ State EstimationWeighted mean of all particles
6️⃣ ResamplingDraw N new particles proportional to weight
7️⃣ LoopRepeat from Step 2 for next frame
📋 Detailed Steps
1️⃣Initialization: Define state vector x (position, velocity). Initialize N particles uniformly. Assign equal weights wᵢ = 1/N.
2️⃣Prediction: xᵢᵗ = A × xᵢᵗ⁻¹ + noise (A = state transition matrix for constant velocity model)
3️⃣Weighting: wᵢ = p(zᵗ|xᵢᵗ) ∝ exp(-d²/2σ²) where d = histogram distance between particle region and target model
4️⃣Normalization: wᵢ = wᵢ / Σwⱼ
5️⃣State Estimation: x̂ᵗ = Σ wᵢ × xᵢᵗ (weighted mean)
6️⃣Resampling: High-weight particles duplicated; low-weight discarded. Methods: Systematic or Multinomial resampling.
✅Handles non-linear, non-Gaussian distributions. Robust to occlusion. Can track multiple objects simultaneously.

Explain spatial histograms. How does it differ from histogram of an image? 📊
10 Marks
📊 Standard Image Histogram
Counts frequency of each intensity/color value across the entire image. X-axis: intensity (0–255), Y-axis: pixel count. Completely discards spatial information.
⚠️Two images with completely different pixel arrangements (red-top-blue-bottom vs blue-top-red-bottom) produce IDENTICAL histograms.
🗺️ Spatial Histograms
1️⃣Divide image into grid of non-overlapping cells (e.g., 4×4 = 16 cells)
2️⃣Compute local histogram for each cell
3️⃣Concatenate all local histograms into single long feature vector

Encodes both appearance (what colors) and location (where in the image).

🏛️ Spatial Pyramid Matching (SPM)
L0One histogram for whole image
L14 cells (2×2 grid) → 4 histograms
L216 cells (4×4 grid) → 16 histograms
🔬 Spatiogram (Advanced)

Per bin, stores: frequency + mean position (μₓ,μᵧ) + covariance Σ of pixel positions. Richer continuous spatial description.

FeatureStandard HistogramSpatial HistogramSpatiogram
Spatial infoNoneCoarse (cell-based)Fine (per-bin stats)

Explain the unsupervised learning algorithm: K-means clustering. 🎯
10 Marks
K-means clustering partitions N data points into K clusters, where each point belongs to the cluster with the nearest mean (centroid).
🎯 Objective
Minimize J = Σᵢ Σₓ∈Cᵢ ||x - μᵢ||² where Cᵢ = cluster i, μᵢ = centroid of cluster i
📋 Algorithm Steps
1
Initialization — Choose K initial centroids. Random or K-means++ (probabilistic spread for better convergence)
2
Assignment — Each point x assigned to nearest centroid: C(x) = argminᵢ ||x - μᵢ||²
3
Update — Recompute each centroid: μᵢ = (1/|Cᵢ|) × Σₓ∈Cᵢ x
4
Convergence Check — Repeat Steps 2–3 until centroids stop changing or max iterations reached
🖼️ Image Segmentation using K-means

Each pixel's color (R,G,B) is a data point. K-means groups pixels with similar colors into K clusters. Each pixel replaced by cluster centroid color → segmented image with K color regions.

AdvantagesDisadvantages
✅ Simple and easy to implement❌ Must specify K in advance
✅ Efficient: O(N × K × iter)❌ Sensitive to initial centroids
✅ Works well for large datasets❌ Assumes spherical, equal-size clusters
✅ Fast convergence❌ Sensitive to outliers
💡Elbow Method: Plot inertia vs K; the "elbow" point (where decrease slows) gives optimal K.

Discuss contrast normalization and robust contrast normalization. 🎨
10 Marks
📊 Contrast Normalization
1️⃣Linear (Min-Max) Normalization: s = (r - r_min)/(r_max - r_min) × 255. Simple and fast. Sensitive to outlier pixels.
2️⃣Histogram Equalization: Uses CDF to redistribute intensities uniformly. Formula: s_k = (L-1) × CDF(r_k). Enhances global contrast. May over-enhance some regions.
3️⃣Z-score Normalization: s = (r - μ)/σ. Centers distribution at 0. Used in neural network preprocessing.
🛡️ Robust Contrast Normalization

Standard methods are sensitive to outlier pixels (extreme bright/dark values). Robust methods use resistant statistics:

1️⃣Percentile-based: s = (r - P₁)/(P₉₉ - P₁) × 255. Uses 1st and 99th percentile instead of min/max. Clips extreme outliers. Much more robust.
2️⃣Robust Z-score (MAD): s = (r - median)/MAD where MAD = median(|r - median(r)|). More robust than standard deviation; unaffected by extreme outliers.
3️⃣CLAHE: Local histogram equalization in small tiles (8×8). Clips histogram at a limit before redistribution — prevents noise over-amplification. Widely used in medical imaging, low-light photography.

Explain in detail about different types of camera sensors. 📷
10 Marks
🔵 1. CCD (Charge-Coupled Device)

Working: Light → electrons → charges shifted row-by-row through shift register → single amplifier reads all pixels sequentially.

Characteristics: Very high image quality, low noise, high dynamic range, excellent pixel uniformity (single amplifier). High power consumption, expensive, slower readout. Used in: scientific imaging, microscopy, medical imaging.

🟢 2. CMOS (Complementary Metal-Oxide-Semiconductor)

Working: Each pixel has its own amplifier and readout circuitry. Pixels read in parallel → faster. Additional processing (ADC, noise cancellation) integrated on same chip.

Characteristics: Lower power, faster frame rates, lower cost, can integrate processing on chip. Used in: consumer cameras, smartphones, automotive cameras.

🔴 3. BSI-CMOS (Back-Side Illuminated)

Flips sensor so light hits photodiode directly from back (wiring doesn't block light). Significantly improved low-light performance. Used in modern smartphones and scientific cameras.

⏱️ 4. Global vs Rolling Shutter
🔹Global Shutter — All pixels exposed simultaneously. No motion distortion. Preferred for machine vision with fast-moving objects. Higher cost.
🔹Rolling Shutter — Pixels exposed row by row. Cheaper but causes jello/skew distortion with fast motion.
📏 5. Line Scan Sensors

Only one row of pixels. Object moves past sensor; 2D image built from successive line scans. Used for inspecting moving objects: fabric, paper, metal sheets on conveyor belts.

🎯 6. Area Scan Sensors

Standard 2D frame capture. Used for stationary or slow-moving objects. Most common type in machine vision.

📡 7. Time-of-Flight (ToF) Sensors

Emit infrared pulses; measure return time. Each pixel stores depth value instead of intensity. Used for 3D imaging, gesture recognition, robotics. Example: Intel RealSense, Kinect v2.

📏 1. Line Segmentation — Hough Transform
Line in normal form: ρ = x cosθ + y sinθ (ρ = perpendicular distance, θ = angle)
1
Apply Canny edge detection
2
Initialize 2D accumulator array A(ρ, θ)
3
For each edge pixel (x,y), for each θ: compute ρ = x cosθ + y sinθ, increment A(ρ,θ)
4
Find peaks in A(ρ,θ) above threshold → each peak = one detected line
OpenCV: cv2.HoughLines() or cv2.HoughLinesP() (Probabilistic)
⭕ 2. Circle Segmentation — Hough Circle Transform
Circle defined by: (x-a)² + (y-b)² = r² — three parameters: center (a,b) and radius r
1
Apply Gaussian blur to reduce noise
2
Apply Canny edge detection
3
For each edge pixel and each radius r, vote for all possible centers (a,b)
4
Find peaks in 3D accumulator A(a,b,r) → each peak = one circle
OpenCV: cv2.HoughCircles()
🔷 3. Contour Segmentation
1
Preprocess — Grayscale conversion + Gaussian blur
2
Binary image — Thresholding or Canny edge detection
3
Extract contours — cv2.findContours(); RETR_EXTERNAL (outer only) or RETR_TREE (hierarchy)
4
Approximate — cv2.approxPolyDP() using Ramer-Douglas-Peucker; 4 points → rectangle, 3 → triangle
5
Analyze — Area, perimeter, bounding rect, centroid using cv2.moments()
6
Draw — cv2.drawContours(image, contours, -1, (0,255,0), 2)

Explain in detail about pinhole cameras. 📸
10 Marks
The pinhole camera is the simplest camera model and forms the mathematical foundation for all camera models in computer vision.
💡 Concept

A lightproof box with a tiny hole (pinhole). Light from the scene passes through the pinhole and forms an inverted image on the opposite wall. Each scene point projects exactly one ray through the pinhole to a unique image point.

📐 Projection Equations (Perspective Projection)
x = f × X/Z y = f × Y/Z where f = focal length, (X,Y,Z) = 3D world point, (x,y) = 2D image point
🔑 Key Properties
🔹Objects farther away appear smaller (Z increases → x,y decrease)
🔹Parallel lines converge to a vanishing point
🔹Image is inverted (upside-down and mirrored)
📊 Camera Matrix (Intrinsic Matrix K)
K = [fx 0 cx] Projection: [x] = K × [X] [0 fy cy] [y] [Y] [0 0 1] [w] [Z] [1] where (cx,cy) = principal point, (fx,fy) = focal length in pixels
🔭 Thin Lens Equation
1/f = 1/do + 1/di where do = object distance, di = image distance, f = focal length For objects far away (do >> f): di ≈ f → pinhole model is a good approximation
PropertyPinhole CameraReal Lens Camera
LensNone (just a hole)Physical lens
Image sharpnessSharp at all depthsDepth of field limited
BrightnessVery dimBright (large aperture)
DistortionNoneRadial and tangential
ModelIdeal perspectiveRequires calibration
⚠️ Limitations
❌Does not model lens distortion (radial/tangential)
❌Assumes single center of projection
❌Fails for wide-angle and fisheye lenses
📌 Importance in Computer Vision
✅Foundation of all camera calibration methods (Zhang's method)
✅Used in stereo vision, structure from motion, 3D reconstruction
✅Augmented reality uses pinhole model to overlay virtual objects accurately
✅Pose estimation (PnP problem) uses pinhole projection equations
